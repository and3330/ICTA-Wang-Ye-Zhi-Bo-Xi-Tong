# 小幫手定時素材

## 設定入口

直播間管理 → AI 品牌助理 → **定時素材**。

每筆設定影片時間（例如 `5:30`、`1:05:30`）、聊天室文字，以及選填的
HTTPS 素材連結。可建立多筆，儲存後依時間排序，支援編輯與確認刪除。
編輯使用完整聊天室訊息，保留原本的連結與換行。

## 觀眾端行為

- 一般直播間與嵌入直播間皆支援。
- 使用小幫手身分，在每位觀眾自己的聊天室中顯示；不是彈窗、不是全場廣播。
- 依影片播放時間觸發，不是實際時鐘。暫停不推進；跳轉到較後時間會補上已到點素材。
- 同一次開啟直播間中，每筆最多出現一次，倒轉不重複。
- 重新整理或重新開啟屬於新的一次載入，可能再次顯示；目前沒有跨載入的送達紀錄。
- 連結需由觀眾自行點擊，以新分頁開啟，不會自動跳轉；訊息不解析 HTML。
- 不需要假觀眾，也不需要啟用 AI 自動回覆；預設文字身分為「小幫手」。
- 「互動」裡原有的小提示卡也改為聊天室訊息：標題與內容一併發送，
  同時間的多筆提示都保留；舊顯示秒數不再讓聊天室提示消失。
- 已開啟觀看頁不即時推播後台變更，需重新載入才能保證取得最新設定。

## 介面與資料

沿用 owner 驗證的 `/api/webinars/:id/scheduled-messages` CRUD 端點。
正式定時素材使用 `messageType: "assistant"`、`fakeUserId: null`。
`triggerTime` 為影片起點起算的整數秒，支援 `0` 至 `86400`；
`message` 為 `1` 至 `2000` 字元的非空文字。

POST 範例（不含真實會員資訊）：

```json
{
  "messageType": "assistant",
  "fakeUserId": null,
  "triggerTime": 330,
  "message": "這是今天的講義，請自行下載。\nhttps://example.com/handout"
}
```

PATCH 只更新 `triggerTime` 與 `message`；不可移至另一直播間或套用模擬觀眾身分。
DELETE 刪除該筆設定，不刪除舊聊天室歷史。既有模擬觀眾編輯區不列出正式素材。

這是預先設定的定時訊息，不會在到點時呼叫 LLM 生成文字，也不代表模型訓練。

## 聊天室投票

排程投票與主辦人即時送出的投票，皆在聊天室中顯示可操作的小卡，不建立彈窗。
同時間的多個投票各自保留，選擇、送出、結果、略過與到期狀態互不影響。
卡片不自動取得焦點，不會阻擋影片；可用鍵盤選項及送出。

原有投票期限仍適用：期限內可作答；逾期未答的卡片顯示「投票已結束」，
不從聊天室移除。已投票的卡片保留結果。跳轉到已超過投票期限的位置，
不會重新開啟已結束的排程投票。

沿用 WebSocket `vote` 操作與伺服器驗證的觀眾身分，不變更投票計數規則。
回應新增 `pollId` 以讓多張卡片正確對應結果：

```json
{
  "type": "pollResults",
  "data": {
    "pollId": "<POLL_ID>",
    "results": { "0": 3, "1": 2 }
  }
}
```

`results` 的鍵是選項索引、值是票數。伺服器仍限制投票必須屬於該直播間，
且同一已驗證觀眾 session 對同一投票不重複計票。
